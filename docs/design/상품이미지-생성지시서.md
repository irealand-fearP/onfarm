# ON-FARM 상품 이미지 생성 지시서

코덱스(또는 다른 이미지 생성 도구)에 그대로 넣어서 쓰는 문서입니다.
**9장**이 필요하고, 전부 같은 규격·같은 톤으로 나와야 합니다.

---

## 1. 출력 규격 (9장 공통)

| 항목 | 값 |
|---|---|
| 비율 | **1:1 정사각형** |
| 크기 | **1200 × 1200 px 이상** |
| 배경 | **1순위 투명(PNG) · 2순위 순백 `#FFFFFF`** |
| 파일 형식 | PNG (투명) 또는 JPG (흰 배경) |
| 파일명 | 아래 표의 `파일명` 그대로 (영문 소문자, 확장자 포함) |

투명 배경이 안 되면 **순백 배경**으로 주세요. 누끼는 이쪽에서 처리하겠습니다.
회색·베이지·그라데이션 배경은 쓰지 마세요. 화면에서 파스텔 타일 위에 올라가기 때문에 배경색이 있으면 다 어긋납니다.

## 2. 절대 금지

- 글자·숫자·로고·워터마크 (한글이든 영문이든 **텍스트 일절 금지**)
- 사람, 손, 얼굴
- 브랜드 포장지, 상표, 스티커
- 접시·도마·식탁보 등 배경 소품
- 조리된 상태 (자른 것, 익힌 것, 요리한 것)
- 과도한 그림자, 강한 색보정, HDR 느낌

## 3. 공통 스타일 (모든 프롬프트 앞에 붙일 것)

```
Professional e-commerce product photograph, single subject centered,
studio softbox lighting from upper left, clean soft shadow directly beneath,
pure white seamless background, natural realistic colors, sharp focus,
high detail, shot on 85mm lens, f/8, no text, no watermark, no props,
no hands, no packaging, square 1:1 composition with generous margin around
the subject.
```

한국어 도구를 쓰신다면:

```
전문 이커머스 상품 사진, 피사체 하나만 중앙 배치, 좌측 상단 소프트박스 조명,
아래쪽에 부드러운 그림자, 순백 무배경, 자연스러운 색감, 선명한 초점,
85mm 렌즈 f/8 촬영 느낌, 글자·워터마크·소품·사람 손·포장지 없음,
정사각형 구도에 여백 넉넉히.
```

## 7. 품질 체크 (받기 전에 한 번만 봐주세요)

- [ ] 9장이 **같은 밝기·같은 각도**로 보이는가 (한 장만 어둡거나 위에서 찍힌 느낌이면 다시)
- [ ] 글자·워터마크가 하나도 없는가
- [ ] 배경이 완전히 하얀가 (연회색·크림색 섞이면 안 됨)
- [ ] 피사체가 정사각형 안에서 잘리지 않고 여백이 있는가
- [ ] 실제 그 품목으로 보이는가 (감자와 고구마, 배와 사과가 헷갈리지 않게)
