## ⚠️ 반드시 지킬 것 — 개체 단위 분할

구축 방식이 **"카메라 5대 × 0°/90°/180°/270° × 상·하부 = 제품 1개당 40장"** 이다.
같은 실물을 40장 찍은 근접중복이므로 **이미지 단위 무작위 분할은 누출**이다.

같은 실수의 전례가 있다: 한바구니 프로젝트가 Fruits-360(턴테이블 연속 프레임)을 무작위 8:2로
나눠 val 98.22%를 기록했지만, 미사용 데이터셋으로 재측정한 실제 Top-1은 61.4%였다.

- 분할 키는 **실물 개체 ID**(라벨 JSON의 종ID/촬영정보에서 파생)로 잡는다.
- 데이터셋이 제공하는 `1.Training` / `2.Validation` 구분을 그대로 쓰고, 자체 재분할을 하지 않는 편이 안전하다.
- 스튜디오 촬영(흰 배경·정면 조명)이라 **어르신 폰 사진과 도메인이 다르다**. 실환경 평가셋을 별도로 만들어
  거기서 나온 숫자만 대외 발표에 쓴다.

## 품목 정합 — 카탈로그를 데이터에 맞춘다

| ON-FARM 현재 카탈로그 | AI 허브 |
|---|---|
| 사과 · 배 · 감귤 · 양파 · 감자 | ✅ 있음 (겹치는 5종) |
| 고구마 · 건고추 · 복숭아 | ❌ **없음** |
| — | 무 · 배추 · 마늘 · 양배추 · 감 (우리에게 없음) |

학습 전에 카탈로그를 정렬하지 않으면 한바구니의 "죽은 라벨 12개"가 재발한다.
무·배추·마늘은 천안 로컬푸드 주력 품목이라 **카탈로그를 10종으로 넓히는 방향**을 권한다.
(`src/db/seed.ts`의 `SEED_PRODUCTS` + `src/ai/providers/heuristic.ts`의 `PROTOTYPES` 동시 수정)

## 수령 절차

### 1) 승인 (사용자만 가능)

1. https://aihub.or.kr 로그인
2. [농산물 품질(QC) 이미지](https://aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&aihubDataSe=data&dataSetSn=149) 접속
3. **다운로드 신청** → 활용목적 작성 → 승인 대기
4. 승인 후 마이페이지에서 **API Key 발급**(메일 수신)

승인 없이 API Key만 있으면 `HTTP 502 / "다운로드 서비스는 홈페이지에서 신청 및 승인 후 이용 가능합니다"` 가 뜬다.

### 2) 받기

```bash
curl -o aihubshell https://api.aihub.or.kr/api/aihubshell.do && chmod +x aihubshell
export AIHUB_APIKEY='발급받은키'
./aihubshell -mode l 149        # 파일 트리 (승인 없이도 조회 가능)
```

**① 라벨 전체 먼저 (약 150 MB).** 스키마·등급 분포·개체 그룹 키를 확인하는 단계.

```bash
./aihubshell -mode d -datasetkey 149 -filekey $(seq -s, 396903 396956)
```

**② 최소 검증 세트 — 배(신고) 전량, 10.5 GB.** 파이프라인 종단 확인용.

```bash
./aihubshell -mode d -datasetkey 149 -filekey 396936,396937,396938,396990,396991,396992,397044,397045,397046,397098,397099,397100
```

**③ 본 학습 — ON-FARM 5품목, 119 GB.**

| 품목 | 용량 | 품종 |
|---|---|---|
| 사과 | 27.6 GB | fuji, yanggwang |
| 감자 | 25.2 GB | seolbong, sumi |
| 양파 | 25.1 GB | red, white |
| 배 | 20.9 GB | chuhwang, singo |
| 감귤 | 20.6 GB | hallabong, onjumilgam |

### 3) 어디서 받을 것인가

- 이 노트북 **C: 여유 28 GB** — ①②만 가능, ③은 불가.
- **E: 외장하드** — 현재 미연결. 연결 시 ③ 가능하나 압축해제에 2~3배 여유 필요(≈300 GB).
- **Colab (권장)** — `aihubshell`을 노트북 셀에서 그대로 실행해 Colab 디스크로 직접 받는다.
  노트북 반납 일정과 무관하고 GPU 학습까지 한 자리에서 끝난다.

## 학습 후 접합 지점

`src/ai/providers/` 에 `CnnVisionProvider` 를 추가하고 `VisionProvider` 인터페이스만 지키면 된다.
`resolveProvider()` 의 폴백 구조와 `validateRecognition()` 스키마 검증은 그대로 통과시킬 것 —
provider 가 준 confidence 를 재검증 없이 신뢰하면 한바구니에서 겪은 게이트 우회가 재발한다.
