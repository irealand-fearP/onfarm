어르신들은 평생 농사를 지어 왔습니다. 모자란 것은 농사 실력이 아니라 내다 팔 길이었습니다.

01

팔 곳이 없었습니다

수확은 해마다 있었지만 내다 팔 길은 마땅치 않았습니다. 있는 길은 값을 남이 정했고, 그 값은 밭에서 멀어질수록 달라졌습니다.

02

길이 생겨도 쓸 수 없었습니다

온라인 판로가 열려도 상품 등록은 사진 편집과 상세페이지 작성부터 시작합니다. 평생 밭을 다룬 손은 대개 그 앞에서 멈춥니다.

03

그 사이를 AI가 메웁니다

사진에서 품목을 찾고 소개글을 대신 씁니다. 가격은 표준 규격에서 나오고 등급은 사람이 확정합니다. AI는 판을 깔아줄 뿐, 결정하지 않습니다.

판매자

문을 열면 이미 등록 1단계입니다

로그인 화면이 없습니다. 홈 대시보드도, 하단 메뉴도 없습니다. 어르신에게 홈 화면은 “무엇을 고를지 정하는 부담”이기 때문입니다. 화면 절반이 사진 찍기 버튼이고, 나머지 일은 그 아래 세 갈래로 접혀 있습니다.

판매자 시작 화면

  • 음성 안내 — 0.92배속으로 천천히 읽어 줍니다. “1번”을 “일번”으로 교정해 읽습니다
  • 음성으로 수량 입력 — “세 상자”라고 말하면 알아듣습니다. 폴백이 아니라 1급 입력 수단입니다
  • 가격·제목·소개글은 서버가 만듭니다 — 판매자가 쓸 글자가 없습니다

소비자

농산물이 아니라 사람이 먼저 보입니다

직거래에서 파는 것은 결국 신뢰입니다. 그래서 카드마다 가격보다 농가 이름이 위에 옵니다. 준비된 상품컷에는 “시연용 이미지”를 붙여, 생산자가 실제로 찍어 올린 사진과 구분합니다.

  • 종류 → 품목 → 지역 3단으로 좁혀 갑니다. 고른 종류에 실제로 있는 지역만 남습니다
  • 상품컷 16종을 원형 아이콘으로 써서 글자를 못 읽어도 고를 수 있습니다
  • 검수 완료 배지는 거점이 실물을 확인한 상품에만 붙습니다
  • 배너 넷이 자동으로 돌고, 각각 실제 분류로 이어집니다

지역 거점

등급은 사람이 실물을 보고 정합니다

AI가 확인한 것과 사람이 확정한 것을 화면에서 끝까지 구분합니다. 거점 담당자가 등급을 직접 고르지 않으면 검수가 끝나지 않습니다. 담당자는 자기 거점에 들어온 물량만 볼 수 있습니다.

원칙

하지 않기로 정한 것들

AI를 쓰는 서비스에서 신뢰는 “무엇을 할 수 있는가”보다 “무엇을 하지 않는가”에서 나옵니다. 아래는 화면 문구에까지 그대로 반영돼 있습니다.

AI는 가격을 만들지 않습니다

가격은 운영자가 미리 등록한 표준 규격에서만 나옵니다. 화면에도 “운영자가 미리 정한 표준 가격입니다”라고 적습니다.

AI는 등급을 확정하지 않습니다

AI가 낸 값은 끝까지 “참고 판정”입니다. 소비자 화면에 보이는 확정 등급은 거점 담당자가 실물을 보고 고른 값입니다.

AI는 식품 안전성을 검사하지 않습니다

무농약·잔류농약처럼 검증할 수 없는 표현은 자동 생성 문안에서 걸러냅니다.

없는 것을 광고하지 않습니다

할인율·쿠폰처럼 실제로 없는 기능은 배너 문구에도 쓰지 않습니다. 기능이 없는 메뉴는 화면에 두지 않습니다.

시연 상태를 숨기지 않습니다

준비된 상품컷에는 “시연용 이미지”가 붙고, 자동 로그인 중이면 화면 하단에 그 사실이 적혀 있습니다.

사진을 밖으로 보내지 않습니다

기본 판정은 기기와 서버 안에서 끝납니다. 외부 전송이 없다는 사실을 화면 상단에 계속 표시합니다.

한 디자인, 두 밀도

어르신도 젊은 판매자도 같은 화면을 씁니다

큰 글씨는 어르신에게 필수지만 젊은 판매자에겐 촌스럽게 읽힙니다. 그렇다고 화면을 두 벌 만들면 관리가 두 배가 됩니다. 그래서 기준 단위 하나만 바꿔 크기를 조절합니다. 색과 구조는 완전히 같습니다.

/* 이 변수 하나가 글씨·버튼·여백·아이콘을 모두 끌고 간다 */
body.seller                          { --u: 1;    }  /* 크게 · 기본값 */
body.seller[data-density="compact"]  { --u: 0.82; }  /* 보통 */
크게 (기본)보통
본문19px15.6px
주 버튼 높이68px55.8px
수량 버튼82px67.2px
전환은 판매자 화면 우측 상단 가⁻ / 가⁺ 버튼 한 번이고, 선택은 기억됩니다. 기본값이 “크게”라 아무것도 하지 않는 사용자가 손해 보지 않습니다.

git clone https://github.com/irealand-fearP/onfarm.git
cd onfarm

npm install
npm run seed     # 데모 데이터 생성
npm start        # http://127.0.0.1:4173
필요한 것은 Node.js 22.5 이상 하나뿐입니다. 내장 SQLite를 쓰기 때문에 외부 데이터베이스도, 클라우드도, 프론트엔드 프레임워크도 없습니다. 화면은 순수 HTML·CSS·JavaScript입니다.
